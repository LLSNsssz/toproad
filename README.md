# 탑로드 (TOP ROAD)

유튜브 광고에 자주 나오는 "게이트 고르기 + 분대 사격" 러너 게임을 브라우저용으로 만든 것입니다.
빌드 없이 `index.html` 한 파일로 동작합니다.

플레이: https://llsnsssz.github.io/toproad/

## 실행

```bash
# 파일을 브라우저로 바로 열어도 되고, 정적 서버로 띄워도 됩니다.
npx serve .
```

## 플레이 방법

- 분대는 자동으로 전진하면서 사격합니다. 드래그(모바일) 또는 ← → / A D 키(PC)로 좌우 이동.
- 길은 3차선입니다. 분대 중심(말풍선의 ▼)이 있는 차선이 선택된 차선입니다.
- 작전이 끝나면 코인으로 `출격 전 정비`에서 업그레이드합니다. 진행 상황은 브라우저 `localStorage`에 저장됩니다.

### 구간(기믹)

| 구간 | 등장 | 내용 |
|---|---|---|
| 게이트 선택 | 1 | `+N` / `×2` / `-N` / `÷2`. 숫자 게이트는 쏘면 숫자가 올라가고, 최대치가 되면 총알이 통과합니다. |
| 좀비 웨이브 | 1 | 대열(횡대·종대·화살촉·차선 장벽·협공). 작전이 오를수록 좀비가 더 단단해집니다. |
| **3갈래 러시** | 1 | 왼쪽은 `+1`이 계속 내려오고, 가운데는 좀비 둥지(버스)가 좀비를 쏟아내고, 오른쪽은 쏴서 부숴야 열리는 보상 금고(`+99` 같은 대량 병력, `×2`, 화력 UP)입니다. |
| 무기 상자 | 2 | 3갈래 러시의 보상이 무기 상자로 바뀝니다. 작전 2의 첫 상자는 항상 기관총. |
| 대량 러시 | 3 | 모래주머니 벽이 터지면서 좀비 떼가 쏟아집니다. |
| **좀비 탑 공성** | 11 | 대량 러시가 공성전으로 바뀝니다. 좀비가 모래주머니 벽을 타고 3~5층으로 쌓이고, 꽉 찬 줄은 벽을 넘어옵니다. 벽 뒤에 숨은 좀비는 피해를 40%만 받으니 벽 위로 올라온 꼭대기를 쏘세요. 분대는 벽 14m 앞에서 최대 5초 멈추고, 그때까지 남은 좀비는 벽을 부수고 쏟아집니다. |
| 마이너스 장벽 | 4 | 피할 수 없는 빨간 벽. 쏴서 숫자를 뒤집어야 합니다. |
| 폭발 드럼 지대 | 6 | 빨간 드럼을 쏘면 주변 좀비까지 연쇄 폭발. |
| 충전 게이트 / 톱날 구간 | 7 | 쏠수록 배수가 오르는 게이트 / 좌우로 움직이는 톱날 피하기. |
| 정예 관문 | 9 | 분대가 멈추고 돌연변이 대장과 1:1. 대장도 내려찍기를 씁니다. |
| 적 분대 | 2 (결전 작전) | 빨간 병사 무리가 다가옵니다. 부딪히면 1:1로 서로 줄어드니, 쏴서 줄이거나 다른 차선으로 피하세요. |

### 무기

소총 → 기관총(2) · 샷건(3, 사거리 짧음) · 로켓(5, 범위 피해) · 레이저(10, 관통) · 화염방사기(14, 사거리 짧음).
같은 무기를 또 먹으면 ★이 올라갑니다(최대 ★5). 무기는 작전마다 소총 ★1로 시작합니다.

### 결전 (성벽 작전)

작전 2, 그리고 그 뒤의 짝수 작전(×0 제외)은 바다 위 성벽 길에서 치르는 **결전**입니다. 좀비 대신 빨간 병사가 나오고, 좀비 둥지는 적 병영이 됩니다.

1. 성벽 끝에 숫자가 붙은 **적군**이 기다립니다. 다가가면서 쏘면 숫자가 줄어듭니다. 단, 돌격 전에는 방패벽 때문에 최대 60%까지만 줄일 수 있습니다.
   - **적 전열 탑 쌓기 (작전 4부터):** 분대가 75m 안에 들어오면 뒤쪽 병사들이 몰려와 맨 앞줄 위로 올라탑니다. 앞줄 13열이 2층, 3층으로 쌓이면서 사람 탑 세 개가 솟고, 층이 높은 열일수록 단단합니다(층당 장갑 +15%). 쏘면 그 열의 꼭대기가 무너집니다. 로켓은 옆 열까지 무너뜨리고, 레이저·화염방사기는 장갑을 덜 받습니다.
   - 최대 층수는 작전이 오를수록 높아집니다: 작전 4 → 2층, 8 → 3층, 15 → 4층, 25 → 5층, 37 → 6층, 52 → 7층. 적군 수도 기대 병력의 2.4배에서 최대 3.4배까지 커집니다(작전 52에서 약 3,600명).
2. **거인 장군**이 앞으로 나와 싸웁니다. 내려찍기·돌진·충격파를 피하면서 쓰러뜨리세요.
3. 장군이 쓰러지면 `CHARGE FORWARD!` 번개 일제사격이 탑 꼭대기에 떨어져 적군을 쓸어버리고 탑을 2층쯤 무너뜨립니다. 화력이 높을수록 더 많이 쓰러뜨립니다. 돌격하는 동안 탑이 다시 솟고, 부딪히는 순간 `와르르!` 무너집니다.
4. 두 군대가 돌격해 **1:1로 상쇄**됩니다. 내 분대가 더 많이 남으면 승리합니다.

결전에서는 화력(일제사격)과 병력 수(1:1 충돌)가 둘 다 중요합니다. 지면 결과 화면이 적군이 몇 명 더 많았는지 알려줍니다.

### 보스

결전이 아닌 작전은 끝에 보스가 나옵니다. 보스는 공격하기 전에 바닥에 빨간 구역을 칠하니, 그 차선에서 벗어나면 피해를 받지 않습니다.

| 보스 | 등장 | 스킬 |
|---|---|---|
| 도살자 | 1 | 내려찍기, 돌진(끝나고 등을 보이면 피해 1.5배), 소환, 충격파(초록 차선만 안전) |
| 산성 여왕 | 5 | 산성탄(웅덩이가 남음), 소환, 산성 내려찍기 |
| 철갑 거인 | 10 | 바위 투척, 돌진, 충격파, 내려찍기 |

- 작전 5부터는 체력 50%에서 2단계가 됩니다. 작전 10부터는 30%에서 분노합니다.
- 작전 ×5는 대형 보스, ×0은 군단장입니다. 군단장은 66%에서 방어막을 치니, 기둥 3개를 부숴 기절시켜야 합니다.
- 오래 끌면 광폭화해서 직접 짓밟으러 옵니다.

## 난이도 설계

- 모든 수치는 "그 작전에서 예상되는 플레이어 화력으로 몇 초"라는 기준으로 계산합니다(`E(n,s)`). 예상 화력에는 예상 병력 수, 예상 업그레이드(기준 플레이어 시뮬레이션), 예상 무기가 들어갑니다.
- 좀비 한 마리를 잡는 데 필요한 탄 수는 작전 1의 1.5발에서 작전이 오를수록 최대 4.5발까지 늘어납니다.
- 작전은 끝없이 이어집니다. 10단위 톱니 곡선(×5·×0은 어렵고, 그 다음은 숨 돌리는 작전), 장기 보정, 연속 패배 시 `지원 사격`(+12%씩, 상한 없음)이 있어서 언젠가는 반드시 넘어갈 수 있습니다.
- 보스 스킬은 항상 안전한 차선이 하나 이상 남고, 0.35초 안에 반응하면 피할 수 있을 때만 발동합니다.
- 결전의 적군 수는 예상 병력의 2.4배(작전 4 이후 작전마다 +0.025배, 최대 3.4배)입니다. 적 병사 한 명의 체력은 예상 화력으로 약 8.5초 쏘면 예상 병력의 70%만 남도록 정합니다. 화력이 기준보다 훨씬 높은 분대는 보스와 같은 방식으로 적군도 단단해집니다. 처음 두 결전(작전 2·4)은 적군이 작습니다. 탑 장갑은 기대 플레이어가 실제로 맞히는 평균 장갑(봇 캠페인으로 측정)만큼 병사 체력에서 빼서, 기대 플레이어에게는 난이도가 그대로이고 장군을 늦게 잡거나 화력이 약하면 더 어려워집니다.
- 밸런스 값은 코드 맨 위 `K` 상수에 모여 있고, 테스트용으로 `window.__toproad`를 엽니다.
