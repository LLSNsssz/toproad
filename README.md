# 탑로드 (TOP ROAD)

유튜브 광고에 자주 나오는 "게이트 고르기 + 분대 사격" 러너 게임을 브라우저용으로 만든 것입니다.
빌드 없이 `index.html` 한 파일로 동작합니다.

## 실행

```bash
# 파일을 브라우저로 바로 열어도 되고, 정적 서버로 띄워도 됩니다.
npx serve .
```

## 플레이 방법

- 분대는 자동으로 전진하면서 사격합니다. 드래그(모바일) 또는 ← → / A D 키(PC)로 좌우 이동.
- 파란 게이트(`+N`, `×2`)는 병력을 늘리고, 빨간 게이트(`-N`, `÷2`)는 줄입니다. 분대 중심이 지나가는 쪽 게이트가 적용됩니다.
- 숫자 게이트는 총알을 맞히면 숫자가 올라갑니다. 빨간 `-8`도 계속 쏘면 `+`로 바뀝니다 (게이트마다 상한 있음).
- 숫자가 적힌 드럼통을 부수면 병력 / 화력 UP / 연사 UP 보상.
- 좀비에 닿으면 병력이 줄어듭니다. 끝에서 나오는 거대 좀비 보스를 잡으면 작전 성공.
- 작전이 끝나면 코인을 받고, `출격 전 정비`에서 시작 병력·화력·연사·보상을 업그레이드합니다.

진행 상황(작전 단계, 코인, 업그레이드)은 브라우저 `localStorage`에 저장됩니다.

## 밸런스 메모

- 작전 N의 좀비 체력 `3 × 1.15^(N-1)`, 보스 체력 `450 × N^1.6 × 1.1^(N-1)`.
- 화면에 그리는 총알은 초당 최대 42발이고, 총 DPS는 그대로 유지되도록 한 발당 피해를 키웁니다.
- 자동 플레이 봇으로 확인한 결과: 업그레이드를 꾸준히 사는 플레이어 기준 작전 20 전후부터 재도전이 필요해집니다.
